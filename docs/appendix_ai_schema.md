The core decision is how to represent a player’s participation in a match. Serve stats, odds, ranking at match time, and pre-match ratings all belong to one player in one match, so they go on the PLAYED relationship. Everything the app computes (prestige, style similarity, head-to-head) is materialized as derived properties or relationships. That keeps traversals short, which helps both GDS projections and an LLM writing Cypher.
